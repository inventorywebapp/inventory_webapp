Google Drive Sync
How it works:
  • Click the button below to import the latest SKU data from your Google Drive folder
  • The system automatically finds the newest Excel file in your folder
  • All SKUs, Categories, and Inventory data will be updated
  • This will NOT delete your existing count records
Your Google Drive Folder:

CheckStockTempFile Folder

Make sure your Excel file is in this folder and shared with the service account.

SKU Merge Tool - Transfer History from Old to New SKU
When to use this tool:
  • When a SKU code has been renamed/changed in the Excel file
  • The old SKU becomes inactive after sync, the new SKU has zero history
  • Use this tool to transfer all count history from the old SKU to the new SKU
  • After transfer, the new SKU will have complete count history preserved
These SKUs are no longer in the current Excel file
